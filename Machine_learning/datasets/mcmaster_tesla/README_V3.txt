README
======

Blind Modeling Tool - Version 3

Welcome to Version 3 of the Blind Modeling Tool.


Software Requirements
---------------------

MATLAB

- MATLAB R2022b or later is recommended to run the MATLAB aiding tools and examples.
- The current tools were developed and tested using MATLAB R2025b.
- Deep Learning Toolbox is required for training the provided MATLAB FNN and LSTM neural network examples.
- Submitted SOC estimator models should not require additional MATLAB toolboxes unless otherwise specified by the submission guidelines.

Python

Python is required only for users who want to run the provided Python examples or develop/test Python SOC estimator models.

- Python 3.10 (64-bit) is required for the provided Python model testing workflow.
- Required Python packages:
  - numpy >= 1.24
  - scipy >= 1.10
  - matplotlib >= 3.7
  - torch >= 2.0

Python can be installed directly from Python.org or through Anaconda.

Installation Links

- MATLAB: https://www.mathworks.com/downloads/
- Python: https://www.python.org/downloads/
- Anaconda: https://www.anaconda.com/download


What's New in Version 3
-----------------------

- Updated submission guidelines to include Python submissions.
- Updated the aiding tools used for model development and evaluation to support Python submissions.
- Updated the neural network training examples to include Python examples.
- Updated the SOC estimation model examples to include Python submissions alongside the existing MATLAB submissions.


Contents of the ZIP Files
-------------------------

1. 0-Documentation.zip

   Contains the submission guidelines, documentation, and evaluation instructions.


2. 1-Open Data_Updated_30_06_2026.zip

   Contains the battery datasets used for model development.


3. 2-Aiding Tools.zip

   The Aiding Tools package contains utilities to assist users in preparing, validating, and analyzing SOC estimation models.

   1. Model Submission Test Tool

      Validates a model submission before upload by checking that the submission package is correctly structured and can be processed successfully. It reports any errors that need to be fixed prior to submission.

   2. Concatenation Tool

      Combines multiple battery data files into a single continuous dataset. This is useful for creating larger datasets for training machine learning models or other algorithms.

   3. Figure Data Extraction Tool

      Extracts numerical data from MATLAB (.fig) output figures generated by the evaluation tool. This allows users to reproduce plots or perform additional analysis of the evaluation results.


4. 3-Neural Network Training Examples.zip

   - Contains MATLAB and Python example scripts for training feedforward neural network (FNN) and long short-term memory (LSTM) SOC estimation models.
   - Demonstrates the training workflow, explains how to extract trained network parameters, and provides guidance for implementing trained neural network models.
   - See the included README.txt for instructions on running the MATLAB and Python examples.
   - Python package requirements are provided in the included requirements.txt.


5. 4-SOC Estimation Model Examples.zip

   Contains MATLAB and Python SOC estimation examples that follow the current submission guidelines and demonstrate the required submission format.
